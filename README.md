# Apki-email - Email Landing Page
A responsive-style landing page built with only HTML and CSS.It features a sky-themed hero section with a background image, a bold headline with a highlighted keyword, and a pill-shaped email subscription form.

## Features
-Full-screen hero section with a sky background image
-Navigation bar with Home, Plans,Gallery and Contact links, plus SignIn and SignUp buttons
-Curved underline hover effect on each menu item
-Bold headline with a highlighted "Read" keyword
-Rounded email input field with a styled "Send"button
-Social media icons (Facebook,Instagram,Twitter)
-Clean layout built with Flexbox

## Built With

-HTML5
-CSS3(Flexbox,background image,hover effects)
-[Font Awesome](https://fontawesome.com) for icons
-[Google Fonts](https://fonts.google.com)(Roboto)
