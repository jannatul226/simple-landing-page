## About the Project

**Apki-email** is a front-end landing page designed to give visitors a clean first impression and a simple way to get started. It combines a clear navigation bar, a bold hero section over a sky-themed background, an email subscription form, and social media links, all built with a focus on readability, visual balance, and a polished user interface.

## Key Features

- **Intuitive navigation:** quick access to Home, Plans, Gallery, and Contact pages
- **Authentication entry points:** dedicated Sign In and Sign Up buttons
- **Engaging hero section:** bold headline with a highlighted keyword and a full-width background image
- **Email subscription form:** rounded input field with a prominent call-to-action button
- **Social integration:** Facebook, Instagram, and Twitter links
- **Consistent typography:** Roboto font loaded through Google Fonts
